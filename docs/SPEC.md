# nullshell 架构规范

本文定义当前架构和长期约束，不记录迁移计划、发布状态或逐项操作步骤。

## 产品与宿主边界

nullshell 是 Quickshell 的 QML 界面配置与补充工具。桌面没有常驻任务栏；按需面板提供状态、搜索和控制。当前支持 Linux/Hyprland，其他合成器不因存在适配层就视为受支持。

- 优先使用 Quickshell 原生 API。仅在有明确协议缺口时增加 Rust 能力；已有可靠命令可以通过有界适配器调用，不为了统一接口再包一层。
- 安装软件、部署用户配置、启动会话是独立动作。默认安装不部署用户 QML，不替换 Quickshell，不改写偏好或隐式迁移状态。会话由使用者管理；本文不指定用户配置放在哪个仓库。
- 桌面使用 Quickshell 原生配置发现。helper 和 QML 可以独立更新，但必须兼容实际调用的协议。系统 greeter 资源是单独、由系统管理的例外。打包和发行版路径留在集成层。

## 分层与交互

| 层 | 职责 |
| --- | --- |
| View | 布局、焦点、动画和页面草稿；不构造系统命令，不认证。 |
| 应用服务 | 操作、共享状态和请求生命周期；按钮、搜索与 IPC 复用同一个所有者。 |
| 适配器 | 从权威来源读取、验证并转换数据；处理可用性、取消、超时、断线与重连。 |
| 系统接口 | Quickshell 原生服务、宿主协议和必要的 helper。请求受理不等于操作完成。 |

概览回答「现在是什么状态」，详情承载同一领域的对象、参数和说明。全局搜索只收录能打开的页面或可直接执行的动作，不索引只读的领域数据，也不为同一动作的参数堆出多个入口。通知和 OSD 表达事件与短期反馈。

布局按容器的实际可用宽高调整。独立区块默认上下排；只有并排有明确用途（如对照或共同操作），且当前空间足以保证标签可读、控件易操作时，才放在同一行。空间不足时换行、堆叠或让内容区滚动，不靠挤小控件来维持一行；有时限的确认与回退必须保持可见。分离窗口应把额外空间用在需要它的内容上，而不是放大固定面板的留白。

可分离详情移动已有页面实例，保留草稿、选择和操作；重复打开时聚焦已有窗口。订阅按实际可见页面维持，不能因为主面板收起而使分离窗口失效。领域服务已经受理的请求不随页面卸载而消失。

## 进程与权限

| 进程 | 职责与边界 |
| --- | --- |
| Desktop | 面板、通知、OSD、壁纸与交互策略。重启不得影响应用、锁屏或正在进行的认证。 |
| Locker | 独立用户进程，使用 Wayland session-lock 与 PAM；认证期间不得热重载。 |
| Polkit agent | 独立用户进程；授权决策由系统 Polkit authority 作出。 |
| Greeter | greetd 专用账户进程。只使用系统部署的代码；可读取验证后的外观数据，不加载用户 HOME 下的代码。 |
| Helper | 按能力选择进程寿命：短任务完成即退出，睡眠协作随会话，Settings 后端由 D-Bus 激活。不引入通用常驻宿主。 |

睡眠协作进程持有 logind 的延迟抑制器。只有合成器确认锁定后才提前释放；失败仍受 logind 最大等待时间约束。它不接管物理键、合盖或系统挂起策略。启动示例及宿主要求见 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 配置、状态与回退

默认值、用户配置和允许由 UI 持久保存的覆盖分别管理。每个状态域只有一个写入者。无效热加载保留上一次有效值；恢复默认应回到用户配置，而不是把整份运行态写回去。

- **外观**：桌面决定有效模式，Settings portal 只读发布。greeter 可以消费单向导出的颜色与壁纸副本；两个数据域独立失败，不互相重置，也不能反写用户偏好。
- **显示**：helper 查询并验证；试用仅改变运行态。用户确认后合成器持久化匹配屏幕组合的记录。未确认、失效或不匹配时，恢复已确认布局或原生兜底；恢复不依赖桌面进程。
- **空闲**：调暗、锁屏和息屏是桌面策略；Keep Awake 暂停计时并独立持久化。不把系统挂起或硬件电源策略混入。
- **材质**：模糊是可选能力。合成器未知、禁用或无法确认能力时使用不透明底色；锁屏自行绘制壁纸，不读取桌面截图。

配置字段、路径和覆盖细节见 [CONFIGURATION.md](CONFIGURATION.md)；显示试用及加载接口见 [DISPLAYS.md](DISPLAYS.md)。

## 扩展与验收

引入新后端能力前，说明原生 API 的缺口、权威数据源、输入输出、超时和退出条件。`nullshell-helper` 的公开接口与内部模块结构独立；协议详见 [BACKEND.md](BACKEND.md)。

预览使用隔离服务；不注册生产通知或认证代理，不执行锁屏或电源动作。界面需检查真实渲染、键盘焦点、窄宽和降级状态。自动化覆盖协议、配置和回退，不把预览或虚拟热插拔当作 PAM、真实睡眠或物理连接器的验收。入口见 [DEVELOPMENT.md](DEVELOPMENT.md) 和 [TESTING.md](TESTING.md)。
